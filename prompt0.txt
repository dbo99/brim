# PROMPT 0 — BRIM Master Skeleton / Baseline Prompt



I’m continuing work on BRIM / PortaTreasure2.



BRIM currently means “BLM-California Resources Information Mapper,” though the name is not final. It is a browser-based Leaflet/R map for BLM-California water-resource screening and situational awareness. It helps users review BLM lands alongside water-resource datasets, live conditions, agency services, local layers, and external reference layers without requiring ArcGIS Pro, VPN, or many separate agency websites.

The project is built mostly in R. Internal/project spatial processing is generally EPSG:3310 California Albers. Leaflet/browser output is WGS84/EPSG:4326.

USGS GW circles should have fixed radius. Fill color encodes latest depth to water. Dark/heavier outline indicates older/stale measurement. Nested/co-located wells use a distinct square/multiwell marker.



Known issue to investigate next:
  
  The Local Layers GW Bulletin / groundwater basin enriched popup sometimes stops working after map use or layer toggling. On fresh load, the cursor changes and popups open with acreage and percent BLM ownership. Later, the cursor no longer changes and popups do not open, even after other layers are turned off. This may be a Leaflet pane, z-index, pointer-events, stale layer object, or popup-binding problem.
