# BRIM representative sample data

These files are intentionally small and are included only so a developer
or coding agent can inspect representative BRIM schemas without production
geospatial inputs or caches.

Included examples:

- `conveyance_facilities_sample.csv`: canonical facility attributes.
- `conveyance_segments_sample.csv`: canonical segment attributes.
- `external_service_catalog_sample.csv`: External Layers catalog schema.
- `conveyance_lines_sample.geojson`: small spatial sample when generation
  succeeded; see `SAMPLE_DATA_CREATION_REPORT.csv`.

These samples are not authoritative production data and are not intended
to build the complete BRIM HTML.
